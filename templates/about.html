About Melanoma CDSS

An AI-powered clinical decision support system for melanoma detection and AJCC stage prediction.

Objective

Support clinicians with deep-learning classification of dermoscopic lesions (Benign vs Malignant), visual explanations via Grad-CAM, rule-based AJCC staging, and automatic diagnostic PDF reports.

Models

  • EfficientNetB0 — transfer learning + fine-tuning
  • MobileNetV2 — lightweight transfer learning + fine-tuning
  • Hybrid — combines both models (soft vote 0.7 × EfficientNet + 0.3 × MobileNet; optional majority / highest-frequency voting)

Dataset

Primary: SIIM-ISIC 2020. The data layer is modular so HAM10000 can be added by switching ACTIVE_DATASET in config.

Explainability

Grad-CAM heatmaps are generated only when the prediction is Malignant. Benign predictions display: “No malignant regions detected.”

AJCC Staging

If malignant, clinical parameters (Breslow thickness, ulceration, mitotic rate, lymph node involvement, metastasis) drive AJCC 8th Edition stage groups (Stage 0–IV) with risk level, recommendation, and follow-up guidance.
