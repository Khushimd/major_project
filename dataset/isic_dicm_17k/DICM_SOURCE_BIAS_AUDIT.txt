11. NON-MELANOMA vs BENIGN
============================================================

DICM class=0 is NOT a clean benign class.
DICM class=1 is NOT a clean melanoma class.

What the official class column actually tracks in this metadata:
  class=1  <->  almost entirely benign_malignant in {malignant,
                indeterminate/malignant}
  class=0  <->  benign, missing, or indeterminate; never 'malignant'

So official class is closer to a malignant vs not-malignant split than
to a pure melanoma vs benign split.

Diagnosis disagrees with that binary:
  - class=0 includes BCC (489), SCC (89), AK, and other non-nevus disease
  - class=1 includes BCC (1009) and SCC (587) that were tagged malignant
  - class=0 also includes 3 rows whose diagnosis is melanoma
  - class=1 diagnosis is melanoma for 6,787 / 8,530 (79.6%)

The current experiment used official class=1 as the melanoma pool.
That avoided treating class=0 as benign, which was correct, but it also
imported malignant keratinocyte cancers as if they were melanoma.

That construction avoids mislabeling non-melanoma disease as benign,
but it creates a SOURCE confound:
  melanoma images come from the DICM 17K collection;
  benign images come from ISIC 2020.
A model can partly learn collection/camera/year style instead of
melanoma biology. This audit does not measure how large that effect is.
